# Ruslan Xray Gateway

VPN-шлюз для **Home Assistant OS**. Устройства на выделенном Ethernet-порту или отдельной Wi-Fi сети выходят в интернет через Xray. Управление доступно из Home Assistant через Ingress.

## Что понадобится

- Home Assistant OS на **amd64** или **aarch64** с доступом к магазину приложений.
- Отдельный Ethernet-порт или Wi-Fi-интерфейс для клиентов. Wi-Fi адаптер должен определяться в HAOS и поддерживать режим AP через `nl80211`.
- Полный Xray JSON с VPN-выходом или ссылка на подписку Remnawave с выдачей Xray JSON.
- Резервная копия HAOS и доступ к хосту через WAN или локальную консоль.

## Установка

1. Нажмите кнопку добавления репозитория выше. Вручную это можно сделать в **Настройки → Приложения → Магазин приложений → ⋮ → Репозитории**, указав `https://github.com/ruslan200065/RuslanXRAY_HA`.
2. Найдите **Ruslan Xray Gateway**, нажмите **Установить** и **Запустить**. При первой установке Supervisor собирает образ для вашего устройства.
3. Нажмите **Открыть веб-интерфейс**. При желании включите показ приложения в боковой панели.

## Первый запуск

1. В разделе **Подписка и профили** загрузите Xray JSON, либо сохраните URL подписки, нажмите **Обновить каталог** и **Выбрать профиль**. Для обычной ссылки на готовый Xray JSON снимите галочку добавления `/json`.
2. В разделе **Сеть** выберите WAN с маршрутом по умолчанию и выделенный интерфейс для клиентов. Оставьте режим маршрутизации через VPN-выход, если профиль не требует собственной маршрутизации.
3. Выберите Ethernet с DHCP, Wi-Fi AP или ручную настройку. Например, для свободного Ethernet-порта задайте шлюз `192.168.50.1/24` и пул DHCP `192.168.50.100–192.168.50.200`. Клиентская подсеть должна отличаться от основной сети.
4. Нажмите **Сохранить настройки** → **Проверить и показать правила**. Вернитесь в **Обзор** и нажмите **Включить VPN-шлюз**.
5. Подключите одно тестовое устройство. Проверьте полученный IPv4, адрес шлюза, доступ в интернет и внешний IP клиента. Статус **Шлюз запущен** отражает состояние локальных процессов и правил.

Подробности о трёх режимах, Wi-Fi 5 ГГц и диагностике описаны в [руководстве](xray_gateway/DOCS.md).

Для локальной проверки кода выполните `python -m unittest discover -s tests -v` из корня репозитория.
