# Ruslan Xray Gateway

VPN-шлюз для **Home Assistant OS**. Устройства на выделенном Ethernet-порту или отдельной Wi-Fi сети выходят в интернет через Xray. Управление доступно из Home Assistant через Ingress.

## Что понадобится

- Home Assistant OS на **amd64** или **aarch64** с доступом к магазину приложений.
- Отдельный Ethernet-порт или Wi-Fi-интерфейс для клиентов. Wi-Fi адаптер должен определяться в HAOS и поддерживать режим AP через `nl80211`.
- Полный Xray JSON с VPN-выходом или ссылка на подписку Remnawave с выдачей Xray JSON.
- Резервная копия HAOS и доступ к хосту через WAN или локальную консоль.

## Установка

1. Нажмите кнопку добавления репозитория выше. Вручную это можно сделать в **Настройки → Приложения → Магазин приложений → ⋮ → Репозитории**, указав `https://github.com/ruslan200065/RuslanXRAY_HA`.
2. Найдите **Ruslan Xray Gateway**, нажмите **Установить** и **Запустить**. При первой установке Supervisor собирает образ для вашего устройства.
3. Нажмите **Открыть веб-интерфейс**. При желании включите показ приложения в боковой панели.

## Первый запуск

1. В блоке **Профили** нажмите **Добавить**. Вставьте ссылку на подписку и загрузите каталог или импортируйте полный Xray JSON. Для ссылки на готовый JSON отключите добавление \`/json\`.
2. Выберите профиль. Кнопка **Пинг** измеряет время до HTTPS-ответа от \`www.gstatic.com\` через конфигурацию профиля. Проверка доступна до включения шлюза. При маршрутизации по правилам профиля запрос может идти напрямую.
3. Откройте **Настройки сети**. Выберите режим раздачи и выделенный клиентский интерфейс. Для Ethernet с DHCP можно оставить адрес \`192.168.50.1/24\` и предложенный пул, если они не пересекаются с основной сетью.
4. Сохраните настройки, нажмите **Включить шлюз** и подключите тестовое устройство. Проверьте его доступ в интернет и внешний IP.

Подробности о трёх режимах, Wi-Fi 5 ГГц и решении проблем описаны в [руководстве](xray_gateway/DOCS.md).

Для локальной проверки кода выполните `python -m unittest discover -s tests -v` из корня репозитория.
