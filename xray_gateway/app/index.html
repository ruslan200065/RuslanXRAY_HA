Управление шлюзом

Никакие правила не включаются автоматически. Начинай с проверки профиля и предпросмотра конфигурации.

⚠️ Preview 0.2: TProxy захватывает публичный IPv4 TCP/UDP с выбранного интерфейса и блокирует обычный forward. DHCP и Wi-Fi AP доступны в экспериментальном режиме; проверьте поддержку AP адаптером и сделайте бэкап. Для IPv6 по умолчанию включена блокировка пересылки, но локальный IPv6 трафик на самом интерфейсе остаётся вне VPN.

Ссылка хранится на HAOS. В режиме Remnawave запрашивается /json с постоянным X-HWID. После обновления профили можно выбирать из каталога.

Направление трафика

Загрузка доступных частот адаптера
Указывай только страну фактического использования. Применение страны требует отдельной галочки и запуска AP; при остановке приложение попытается вернуть прежний регион. Адаптеры с self-managed могут по-прежнему запрещать 5 ГГц (no-IR).
При запуске дополнительных сервисов используется выделенный интерфейс. 5 ГГц использует каналы 36–48 без DFS, если их разрешает драйвер и регион. DFS требует разрешения по действующим правилам региона, поддержки драйвера и может запускаться с задержкой из-за проверки радаров. Wi-Fi AP может конфликтовать с NetworkManager HAOS; используйте отдельный USB Wi-Fi адаптер, поддерживающий AP. IPv6 с клиентского интерфейса блокируется.

Предпросмотр правил

Сохраните сеть и нажмите «Проверить и показать правила»

USB Wi-Fi через libusb · RTL8851BU

Экспериментальный драйвер без модуля ядра. Этап 1 — прямое чтение USB-дескрипторов устройства 0bda:b851 и определение точек обмена.

Нажми «Проверить USB через libusb».
—
Это реальный доступ к USB через libusb, но пока не готовая точка доступа: для RTL8851BU предстоит перенести работу с прошивкой, чипом и Wi-Fi кадрами в userspace. Сейчас приложение не захватывает устройство и не мешает Bluetooth.

Альтернативный способ: драйвер ядра

Резервный путь через встроенный модуль HAOS rtw89_8851bu. Для выбранного userspace-пути он не нужен.

Нажми «Проверить USB Wi-Fi».
—
Если драйвера нет в сборке ядра HAOS, дополнение не сможет создать сетевой интерфейс. Для этого нужен модуль, собранный под текущую версию ядра. Если Wi-Fi появился, открой раздел «Сеть» и выбери новый интерфейс для раздачи VPN.
