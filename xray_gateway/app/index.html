Управление шлюзом

Никакие правила не включаются автоматически. Начинай с проверки профиля и предпросмотра конфигурации.

⚠️ Preview 0.2: TProxy захватывает публичный IPv4 TCP/UDP с выбранного интерфейса и блокирует обычный forward. DHCP и Wi-Fi AP доступны в экспериментальном режиме; проверьте поддержку AP адаптером и сделайте бэкап. Для IPv6 по умолчанию включена блокировка пересылки, но локальный IPv6 трафик на самом интерфейсе остаётся вне VPN.

Подписка Remnawave / Xray JSON

Ссылка хранится на HAOS. В режиме Remnawave запрашивается /json с постоянным X-HWID. После обновления профили можно выбирать из каталога.

Полный Xray JSON

Как в RuslanXRAY OpenWrt: сохраняем полный профиль с его native outbounds, routing и balancers. Конфигурация валидируется Xray до записи.

Направление трафика

При запуске дополнительных сервисов используется выделенный интерфейс. Wi-Fi AP может конфликтовать с NetworkManager HAOS; используйте отдельный USB Wi-Fi адаптер, поддерживающий AP. IPv6 с клиентского интерфейса блокируется.
