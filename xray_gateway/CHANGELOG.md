# 0.3.18

- Подписки обновляются в фоне. Панель показывает количество загруженных и пропущенных профилей.
- Выбранный профиль сохраняется при изменении порядка каталога. Обновлённые параметры применяются при однозначном совпадении сервера.
- Если провайдер недоступен или в ответе нет рабочих профилей, прежний каталог сохраняется. HWID сохраняется.

# 0.3.17

- Панель различает запуск точки доступа, проверку DFS, готовность и сбой по состоянию hostapd.
- Каналы с запретом no-IR на self-managed адаптерах недоступны для выбора. После запроса страны бэкенд ждёт подтверждения от ядра и заново проверяет канал.
- Добавлено пояснение по 5 ГГц и схеме с внешней точкой доступа через Ethernet.

# 0.3.16

- Новая панель с включением и остановкой шлюза, списком профилей и настройками сети.
- Проверка HTTPS-задержки через выбранный профиль, в том числе до запуска шлюза.
- Запросы подписок всегда передают индивидуальный HWID. Существующие корректные идентификаторы сохраняются.
- Убраны экраны сетевой диагностики и предпросмотра правил.

# 0.3.15

- Обновлена панель Ingress. Добавлены подсказки первого запуска, поля по выбранному режиму сети и ссылка на RuslanXRAY VPN.
- Статус учитывает состояние Xray, временных сервисов и сетевых правил. Сохранённый пароль Wi-Fi скрыт из ответа статуса.
- Изменения конфигурации и управление шлюзом выполняются последовательно. При ошибке установки правил откатываются только успешно добавленные записи.
- Обновлены инструкции установки и диагностики. Исправлены тестовые данные для разбора каналов Wi-Fi.
